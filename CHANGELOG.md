## 1.0.0 - 2026-10-28

Initial open-source release.

- Run Codex or Claude Code from Linear: mention or delegate an issue to Axis, follow up in the same session, and cancel or steer running work.
- Configure services, routing, storage and credentials with `axis.toml` and the interactive `axis init`.
- Run Relay/Router, Node and Workers with `axis serve` or separate role processes.
- Deploy with Docker/Compose, Linux systemd or managed macOS services.
- Deploy, verify, upgrade, back up and roll back with your coding agent through the bundled `axis-deploy` skill.
