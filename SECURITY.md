# Security policy

Report suspected vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/axisosme/Axis/security/advisories/new):
open the repository's **Security** tab and choose **Report a vulnerability**.
Do not disclose vulnerabilities in public issues or pull requests.

Include the affected version or commit, a description of the impact, and steps
to reproduce with synthetic data. Remove credentials, personal information,
prompts, and provider output from any examples or logs you submit. Maintainers
will review the report privately and coordinate remediation and disclosure.

For the system's authentication, trust boundaries, and sensitive data handling,
see the [security model](docs/SECURITY-MODEL.md).
